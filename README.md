# VANTA — Modern Storefront Template

A clean, responsive front-end ecommerce landing page built with only HTML, CSS and vanilla JavaScript.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript

## Features
- Responsive ecommerce layout
- Dark/light mode
- Mobile navigation
- Product cards
- Wishlist interaction
- JavaScript cart drawer
- Cart subtotal calculation
- Scroll reveal animations
- Newsletter interaction
- No backend
- No framework
- No Python

## Structure
```
storefront-template/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Run
Open `index.html` directly in your browser, or use VS Code Live Server.

## GitHub Pages
Push the files to a GitHub repository, then enable GitHub Pages from Repository Settings → Pages.
